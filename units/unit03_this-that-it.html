Unit 3

This / That / It と指示表現（近くの物・離れた物・話に出た物）

Unit 1・2 で作った be動詞の文に、物や人を指す語を加えます。this と that は話し手からの距離で選び、it はすでに話に出た物を受けます。入試では、疑問文の答えで this / that を it に置きかえられるか、人を it で受けていないかで点が分かれます。

3つの語

この単元で使う3つの語を、先に押さえます。どれも名詞の代わりに物や人を指す語ですが、指し方が違います。

this ／ that（指示語）

目の前の物や人を指し示す語です。話し手の近くにあれば this（これ）、離れていれば that（あれ）を使います。人を紹介するときにも使えます。

This is my pen.（これは私のペンです）
That is a famous station.（あれは有名な駅です）
This is my friend Emma.（こちらは私の友達のエマです）

this ＋ 名詞 ／ that ＋ 名詞

this / that を名詞のすぐ前に置くと、「この〜」「あの〜」の意味になります。this / that と名詞をまとめたものが1つの主語です。

This camera is new.（このカメラは新しいです）
That house is old.（あの家は古いです）
That clock over there is big.（あそこのあの時計は大きいです）

it（代名詞）

すでに話に出た物を受ける語です。「それ」と訳しますが、距離は表しません。疑問文の答えでも、this / that の代わりに it を使います。

This is my bike. It is old.（これは私の自転車です。それは古いです）
Is that your umbrella? — Yes, it is.（あれはあなたの傘ですか。— はい、そうです）
That is my dictionary. It is very useful.（あれは私の辞書です。それはとても役に立ちます）

文の形

this / that が主語：「これは〜です」「あれは〜です」

This主語 is my pen正体・状態・場所

名詞の前に置く：「この〜は」「あの〜は」

That house主語（2語で1つ） is old正体・状態・場所

be動詞の形は Unit 1 と同じ決め方です。主語が I なら am、You なら are、それ以外は1つなら is、2つ以上なら are。this / that / it が1つの物や人を指すときは、主語は1つなので is になります。This camera のように名詞が続いても、指しているのは1つです。

距離で選ぶ

語指すもの例文
this 話し手の近くの物・人
（これ・この）		 This eraser is small.
that 話し手から離れた物・人
（あれ・あの）		 That map is old.
it すでに話に出た物
（それ）		 It is beautiful.

なぜ2つしかないのか。日本語は「これ・それ・あれ」の3つで分け、相手の近くの物を「それ」と呼びます。英語は話し手からの距離だけで this と that の2つに分けます。相手が手に持っている物は、話し手から見て離れているので that で指すのがふつうです。

ここで注意したいのは、「それ」と訳すからといって it を選ぶのではないという点です。it は物を指し示す語ではなく、一度話に出た物を受け直す語です。目の前の物を初めて話題にするときは、距離に合わせて this か that を使います。

it のはたらき

1文目（初めて話に出す）2文目（受け直す）
This is my camera. It is old.
That is a famous garden. It is beautiful.
That is my computer. It is not expensive.
This is my racket. It is not heavy.

なぜ2文目で it に変えるのか。2文目では、どの物の話かがもう分かっています。距離を示し直す必要がないので、指し示す働きのない it を使います。2文目でも this / that を使うと、別の物を新しく指したように聞こえます。

疑問文への答え方

this / that の疑問文には、Unit 2 と同じく Yes か No で答えます。答えの文では、問いの this / that を it に置きかえます。

問いYes の答えNo の答え
Is this your pen? Yes, it is. No, it isn't.
Is that your bike? Yes, it is. No, it isn't.
Is this pencil short? Yes, it is. No, it isn't.
Is that your brother? Yes, he is. No, he isn't.

最後の行のように、this / that が人を指しているときは、答えで it を使いません。男性なら he、女性なら she に置きかえます。問いの語をそのまま繰り返して Yes, this is. と答えることもしません。

短縮形

もとの形短縮形例文
that is that's That's a good idea.
it is it's It's a famous station.
this is 短縮形なし This is my new computer.

that is と it is は縮められますが、this is は縮めません。this の終わりの s のすぐあとに is が続くと発音しにくく、縮めた形が使われてこなかったためです。書くときも話すときも This is の2語のままにします。また、Unit 2 と同じく Yes の答えでは短縮形を使いません。Yes, it is. は縮めず、No, it isn't. は縮めてかまいません。

this / that / it を選ぶ手順

  1. その物が、話に初めて出るかどうかを見る もう話に出ている物なら it。答えの文も同じで、問いに出た物は it で受けます。
  2. 初めて出るなら、話し手からの距離で選ぶ 近くなら this、離れていれば that。over there（あそこに）が付いていれば that です。
  3. 人を指すなら、2文目と答えでは he / she 1文目の this / that は人にも使えますが、受け直すときに it は使いません。
  4. be動詞の形を決める 主語が I なら am、You なら are、それ以外は1つなら is、2つ以上なら are。this / that / it が1つを指すなら is です。

境界になる形

人を紹介する this と、受け直す she / he

This is my friend Emma. のように、人を紹介するときも this を使います。「こちらは〜です」と訳します。ただし、続けてその人を説明する2文目では It is kind. とせず、She is kind. とします。it は物を受ける語で、人には使いません。This is my friend Emma. She is in the tennis club. のように、紹介したあとは she / he で続けます。

this / that と my / your は並べない

「この私の自転車」を this my bike とはしません。this / that も my / your も、名詞の前に1つだけ置く語だからです。This bike is old.（この自転車は古い）か My bike is old.（私の自転車は古い）のどちらかにします。「これは私の自転車です」と言いたいときは、This is my bike. と is をはさみます。

it は名詞の前に置けない

this / that は this camera のように名詞の前に置けますが、it は名詞の前に置けません。it は1語で名詞の代わりをする語なので、it camera という形はありません。「そのカメラ」は、話に出たカメラなら the camera、距離を示すなら this camera / that camera です。

over there と this は一緒に使わない

over there は「あそこに」という意味で、話し手から離れた場所を表します。離れた物を指す語は that なので、That clock over there is big. のように that と組みます。This clock over there は、近くと遠くを同時に言っていることになり、使えません。

入試での出方

形式問われ方
選択疑問文の答えを4択にして、this / that を it に置きかえられるかを問います。人を指す問いでは he / she が正解になります。
並べ替えthat と over there の位置、this を名詞の前に置く形がよく出ます。
誤文訂正This's、Yes, this is.、人を it で受ける文、this my 〜 の4つが定番です。
英作文短縮形 It's / That's を使わせて語数を指定します。どちらも1語と数えます。
読解下線部の it が何を指すかを、本文中の語で答えさせます。直前の文で話に出た物を探します。

よくある間違い

×This's my new computer.
○This is my new computer.

this is は短縮形にしません。縮められるのは that's と it's です。

×Is this your pen? — Yes, this is.
○Is this your pen? — Yes, it is.

答えの文では、問いの this / that を it に置きかえます。

×That is my friend Emma. It is kind.
○That is my friend Emma. She is kind.

人を受け直すときは it ではなく he / she です。

×This my bike is old.
○This bike is old.

this と my は並べません。「私の」を言いたいなら My bike is old. とします。

×Is that camera expensive? — Yes, it's.
○Is that camera expensive? — Yes, it is.

Yes の答えは短縮形にできません。Unit 2 の Yes, I am. と同じ決まりです。

ここまでの形は、次の文でひととおり確かめられます。This pen is long.／This pencil is not short.／This camera is not cheap.／This cat is cute.／That flower is beautiful.／Is that your guitar?／Is this your piano?／That park is famous.／This is a nice room.／This picture is interesting.／Is this umbrella expensive?　どれも、初めて指す物か、すでに話に出た物かを先に確かめてから語を選んでいます。

B語順

日本語に合うように語を並べ替えましょう。文の先頭に来る語も小文字で示してあります。10と11には使わない語が1語ずつ混ざっています。

  1. これは私の辞書です。
    [ my / is / dictionary / this ] .
  2. あれはあなたの自転車ですか。
    [ your / that / is / bike ] ?
  3. この傘は新しくありません。
    [ umbrella / new / is / this / not ] .
  4. あそこのあの時計は古いです。
    [ over / that / is / old / clock / there ] .
  5. それは有名な公園です。1語不要
    [ a / it's / famous / is / park ] .
  6. あの絵は美しいですか。1語不要
    [ beautiful / that / is / picture / it ] ?

E読解

エマがケンの部屋で話しています。対話を読んで、あとの問いに答えましょう。

エマとケンの対話

Emma: This is a nice room, Ken. Is that your guitar?
Ken: Yes, it is. It is new.
Emma: It is beautiful. And is this your piano?
Ken: Yes, it is. It is old, but it is very good.
Emma: ①This picture is interesting. Is it a park?
Ken: No, it isn't. It is a famous garden in Kyoto.
Emma: Is that your dictionary on the desk?
Ken: Yes, it is. ②It is heavy, but it is very useful.

  1. 本文の内容に合うものを1つ選ぶ。
    ア ケンのギターは古い。
    イ ケンのピアノは古い。
    ウ ケンの辞書は軽い。
  2. 本文の内容に合うものを1つ選ぶ。
    ア 写真には公園が写っている。
    イ 写真には京都の有名な庭が写っている。
    ウ エマは写真をおもしろくないと言っている。

  5. 下線部②の It が指すものを、本文中の英語1語で答える。
F自由記述

正解は1つではありません。this / that と it を使って書いてください。

  1. 身の回りの物を1つ this か that で紹介し、続けて it を使ってその物を説明する。例：This is my pen. It is new.
  2. 家族か友達の持ち物について、this か that を使ってたずねる疑問文と、その答えの文を書く。答えは Yes か No で始める

解答と解説

問題を解き終えてから開きましょう。まちがえた問題は、その物が初めて話に出たのか、すでに出ているのかを確かめてから、this / that / it を選び直すと定着します。

  1. ア　This

    人を紹介するときは this を使います。it は人には使いません。続く文が She で受けていることも手がかりです。

  2. イ　it isn't

    答えの文では this を it に置きかえます。No の答えなので短縮形 isn't が使えます。

  3. イ　That

    over there（あそこに）があるので、離れた物を指す that です。it は名詞の前に置けません。

  4. ウ　he

    問いの that は人（兄）を指しています。人を受け直すときは it ではなく he です。

  5. ウ　are

    主語は This picture and that picture で2つです。this / that が付いていても、and で結んだ主語は2つ以上なので are です。

  6. This is my dictionary.

    「これは」の this が主語です。be動詞 is のうしろに my dictionary を置きます。

  7. Is that your bike?

    be動詞 is を主語 that の前に出し、文末に ? を付けます。

  8. This umbrella is not new.

    「この傘」は this umbrella の2語で1つの主語です。not は is のすぐうしろです。

  9. That clock over there is old.

    「あそこのあの時計」は that clock over there で1つの主語です。over there は名詞のうしろに置きます。

  10. It's a famous park.

    不要な語は is です。It's にすでに is が含まれています。

  11. Is that picture beautiful?

    不要な語は it です。「あの絵」は that picture で、it は名詞の前に置けません。

  12. This is my new computer.

    理由の例：this is は短縮形にできないから。
    That's と It's は縮められます。

  13. "Is this your pen?" "Yes, it is."

    理由の例：答えの文では this を it に置きかえるから。

  14. That is my friend Emma. She is kind.

    理由の例：人を受け直すときは it ではなく she を使うから。

  15. This bike is old.

    理由の例：this と my は名詞の前に並べて使えないから。
    My bike is old. でも正解です。

  16. That dictionary over there is very useful.

    理由の例：over there（あそこに）の物は離れているので that で指すから。

  17. This is my new computer.

    this is は縮めずに書きます。

  18. That is my friend Emma.

    人を紹介するときも that / this を使います。That's my friend Emma. でも正解です。

  19. That house is not old.

    「あの家」は that house。That house isn't old. でも正解です。

  20. Is this umbrella expensive?

    主語 this umbrella の前に Is を出します。

  21. It's a famous station.

    It's は1語と数えるので、これで4語です。

  22. 解答例　Is this your camera? No, it isn't.

    答えでは this を it に置きかえます。No, it is not. でも正解です。

  23. That clock over there is not big.

    7語にするため、isn't ではなく is not と書きます。this ではなく that を使います。

  24. イ

    本文に And is this your piano? に続いて It is old, but it is very good. とあります。ギターは新しく、辞書は重いと書かれています。

  25. イ

    本文に It is a famous garden in Kyoto. とあります。エマは This picture is interesting. と言っています。

  26. not

    ケンは Is it a park? に No, it isn't. と答えています。写真は公園ではありません。

  27. この写真はおもしろいです。

    名詞の前の this は「この」と訳します。「この絵はおもしろい」も正解です。

  28. dictionary

    直前のエマの問い Is that your dictionary on the desk? で話に出た物を、it で受け直しています。

  29. 解答例　This is my bike. It is very old.

    1文目は this / that、2文目は it で書けていれば正解です。人を紹介した場合は、2文目を he / she にします。

  30. 解答例　Is that your camera? — No, it isn't.

    問いの this / that を、答えでは it に置きかえます。Yes の答えを短縮形にしていないかも確認しましょう。

この単元のまとめ

初めて指す物は、近くなら this、離れていれば that。名詞の前に置けば「この〜」「あの〜」になります。一度話に出た物は it で受け直し、疑問文の答えでも this / that を it に置きかえます。人を受けるときは it ではなく he / she です。短縮形は that's と it's の2つで、this is は縮めません。be動詞は、this / that / it が1つを指すので is です。
