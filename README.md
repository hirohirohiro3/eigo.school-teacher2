# 中学英語 リスタート教材

中1英語を、指導順に組み直した全16単元の教材。各単元はワークブック（解説＋30問＋解答と解説）と単語帳の2本立て。

スマートフォン縦画面での閲覧を主、A4縦での印刷を副として設計しています。

## 難度基準（2026-09-15 改訂）

**対象は偏差値50〜60の中学3年生。** 到達目標は公立高校入試の標準レベル。「中1の文法を、入試で通用する精度まで」を上限とし、それ以上は狙わない。

改訂前は「中1でつまずいた生徒」向けだったが、実際の授業で対象像が上だったため引き上げた。経緯と設計意図は `REVISION-PLAN.md` にある。

### 問題の構成

設問数は固定しない。**パート構成と設問タイプで規定**し、合計 28〜36問のレンジに収める。

| パート | 内容 | 設問数 | 和訳 |
|---|---|---|---|
| A | 形の確認。4択。主語を長くし、他の単元の要素も選択肢に混ぜる | 3〜6 | なし |
| B | 語順（並べ替え）。**語群は単語単位**。うち2問は余分な語を1語混ぜ、問題文に明示する | 5〜8 | あり |
| C | 誤文訂正。直したうえで**なぜ誤りかを日本語で1行**書かせる | 5〜8 | なし |
| D | 英作文。和文英訳と条件英作文（使用語・語数の指定） | 6〜10 | 和文英訳のみ |
| E | 読解。短い英文を読み、内容一致・空所補充・下線部和訳 | 4〜6 | なし |
| F | 自由記述 | 2〜3 | — |

HTML では `<ol class="q" data-part="A">` のようにパートを指定する。余分な語を混ぜた並べ替えは `<li data-extra="1">` とする（指定しないと語数チェックで落ちる）。

読解本文は `<div class="reading">` に入れる。**その単元までに扱った文法だけで書く。**

| 単元 | 読解の形式 | 語数 |
|---|---|---|
| 1〜2 | 自己紹介文・人物紹介文 | 40〜60語 |
| 3〜6 | 説明文・短い対話 | 60〜80語 |
| 7〜16 | 日記・手紙・対話 | 80〜120語 |

### 解説

現行の構成（図解 → 判定手順 → よくある間違い → まとめ）を土台に、以下を足す。**削るものはない。**

1. **なぜそうなるか** —— 規則の理由を書く
2. **境界事例・例外** —— 数えられない名詞、it と this の違いなど
3. **入試での出方** —— どの形式で問われるかを1〜2行
4. **例文を各パターン3〜4本**に増やす

難度は問題側だけで上げる。解説は薄くせず、むしろ厚くする。

### 語彙

- 1単元の新出語は **25〜40語**
- 高校入試で頻出の中1相当語を意図的に配置する
- 単語帳に**関連語・対義語**を1行足す（`tall ↔ short`）。ただし `v-note` 内に置き、**見出し語には立てない**

## 単元の作り方

CSS はテンプレートに入っているので、**本文だけを書きます**。

```bash
python tools/build.py workbook 3 this-that-it "This / That / It と指示表現" body.html
python tools/build.py vocab    3 this-that-it "This / That / It と指示表現" body.html
python tools/check.py 3
```

`body.html` には `<div class="sheet">` の中身だけを書きます。単語帳の品詞ガイドと画面下の常駐バーはテンプレート側が入れるので、本文に書く必要はありません。

## 検証

単元を作ったら必ず走らせます。

```bash
python tools/check.py 1          # Unit 1
python tools/check.py --all      # 存在する全単元
```

見る項目と制作の手順は `PLAN.md` にまとめてあります。

## 技術的な約束

- 外部画像を使わない。図はすべて HTML と CSS で描く
- JavaScript を使わない（折りたたみは `<details>` 要素）
- 外部読み込みは Google Fonts の Klee One のみ
- ライトモード固定
- スマホ幅 375px で横スクロールが発生しないこと
- 印刷は A4 縦

## GitHub Pages で公開する手順

1. GitHub で新しいリポジトリを作る（Public）
2. このフォルダの中身をアップロードする（`index.html` がリポジトリ直下に来るように）
3. リポジトリの **Settings → Pages** を開く
4. **Source** を「Deploy from a branch」、**Branch** を `main` / `/ (root)` にして Save
5. 1〜2分で `https://<ユーザー名>.github.io/<リポジトリ名>/` が公開される

更新するときは、ファイルを差し替えて push するだけです。

## 単語帳の作り方

1. 確定したワークブック HTML から英単語を全抽出する
2. 屈折形を見出し語に寄せる（cats → cat / plays → play）
3. 累積マスタと突き合わせ、その単元の新出語を確定する
4. 基本語リストに載せる機能語を除く
5. 例文はワークブック本文の文をそのまま使う
6. 完成後、単語帳側の語がワークブック側の全語をカバーしているか機械的に照合する

### 品詞の体系

色は仲間、線の形はその中の区別を表します。

| 系統 | 品詞 | 枠線 |
|---|---|---|
| 緑 | 名詞 | 実線 |
| 緑 | 代名詞 | 破線 |
| 緑 | 数詞 | 点線 |
| 橙 | 動詞 | 太い実線 |
| 青 | 助動詞 | 二重線 |
| 紫 | 形容詞 | 実線 |
| 紫 | 副詞 | 破線 |
| 灰 | 前置詞・接続詞・冠詞・間投詞 | 細い実線 |
| 桃 | 疑問詞 | 実線 |
| — | 熟語 | 灰色の枠のみ |

橙と青はワークブックの図解と同じ色です（橙＝一般動詞、青＝be動詞）。

### 複数品詞の扱い

その単元で実際に使われている用法だけを載せます。別の単元で別の品詞として出てきたら、そこで改めてエントリを立てます。

ただし読み違いの原因になる語（play / watch / clean / cook / walk / drink / help / fast / well / home）は、「別の品詞」バッジで1行だけ注記します。Unit 7 に「品詞が変わる語」の一覧をまとめて置きます。

### バッジ

| バッジ | 中身 |
|---|---|
| 別の品詞 | 同じ綴りで品詞が変わる |
| 綴り注意 | -s / -ing / 過去形で綴りが変わる |
| 使い方 | 語順、冠詞がつかない等 |
| セットで | 対で覚える語 |
