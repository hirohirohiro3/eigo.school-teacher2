Unit 4

接続詞 when / if / because / that

中1 Unit 1 から、文は「主語＋動詞」で1つずつ作ってきました。この単元では、その文を2つつなげて1つの文にします。つなぐ語が接続詞で、ここでは when（〜するとき）・if（もし〜なら）・because（〜だから）・that（〜ということ）の4語を扱います。入試では、どの接続詞を選ぶか、つないだ側の動詞をどの形にするか、コンマをどこに置くかが問われます。

2つの文を1つにつなぐ語

中1 Unit 4 では and but or を学びました。この3語は、語と語、文と文を対等に並べます。この単元の4語はちがいます。一方の文を、もう一方の文の説明として付け足します。

I lived near the forest. I was a child. ↓ when でつなぐ I lived near the forest when I was a child.

接続詞の文　中心になる文のうしろに「接続詞＋文」が付く

I lived near the forest中心の文 when I was a child説明の文

どちらも「主語＋動詞」をそろえた文の形です。接続詞のうしろに語だけを置くことはできません。when a child とは言えず、when I was a child と、主語と動詞をそろえます。

接続詞意味付け足す内容
when〜するとき時
ifもし〜なら条件
because〜だから理由
that〜ということ内容

説明の文は、前に出すこともできます。そのときは、2つの文の境目にコンマを置きます。When I was a child, I lived near the forest.　うしろに置くときはコンマは要りません。意味は変わりません。

when は時を付け足す

when は「〜するとき」です。中心の文がいつのことなのかを示します。

形例文
うしろに置くI lived near the forest when I was a child.
前に出すWhen I was a child, I lived near the forest.
過去進行形と組むWhen I opened the door, the wind was blowing.
気づいたことを言うWhen I arrived at the river, I was very surprised.

中1 Unit 11 で学んだ at seven や on Sunday は、時を語句で示す言い方でした。when を使うと、時を文で示せます。言えることの幅がここで広がります。

疑問詞の when と接続詞の when

中1 Unit 10 の疑問詞 when と、この単元の接続詞 when は綴りが同じです。見分けるところは2つで、文の先頭にあるかどうかと、文の終わりが ? かどうかです。

疑問詞の when接続詞の when
働き時をたずねる時を付け足す
位置文の先頭だけ先頭と文の中
うしろ疑問文の語順ふつうの語順
終わり?.

疑問詞の例は When does the volunteer event start? です。does があり、? で終わります。接続詞の例は I will call you when I get home. です。when のうしろが I get というふつうの語順で、. で終わります。中心の文に時を付け足しているだけです。

if は条件を付け足す

if は「もし〜なら」です。起きるかどうか決まっていないことを条件として置きます。

形例文
前に出すIf it is sunny tomorrow, we will clean up the river.
うしろに置くWe will work outside if the weather is sunny.
できないことを言うIf we throw away plastic bottles in the river, we cannot protect the birds and the trees.
結果を言うIf we plant seeds in spring, the vegetables grow well.

when と if のちがいは、必ず起きることかどうかです。朝が来る、家に着くといった必ず起きることには when を使います。晴れる、雨が降るといった起きるか分からないことには if を使います。

when と if の中では未来を現在形で言う

ここは中2で最も間違えやすいところです。when と if のうしろの文では、未来のことでも will を使わず、現在形で言います。

未来のことを言う文　中心の文は will、if のうしろは現在形

If it rains現在形 , we will readwill ＋ 原形
中心の文when / if のうしろ例文
will ＋ 原形現在形If it is sunny tomorrow, we will clean up the river.
will ＋ 原形現在形（3人称単数の -s はつく）If it rains tomorrow, we will read about the environment in the classroom.
will ＋ 原形現在形I will call you when I get home.

なぜ現在形なのか。if と when のうしろは、話のはじめに置く条件や時です。これから先のことだと中心の文の will がすでに示しているので、条件の側では未来の印を重ねません。英語はここで形を軽くします。

現在形といっても、3人称単数の -s は落としません。If it rains tomorrow の rains には -s がついています。中1 Unit 9 の決まりはそのまま働きます。

この決まりが働くのは when と if のうしろだけです。because と that のうしろでは、未来のことは will で言います。I am glad because you will join the event.／I promise that I will join the event again.

because は理由を付け足す

中1 Unit 10 で、Why 〜? には Because 〜. で答えると学びました。because は理由を示す語で、1つの文の中でも使えます。

形例文
うしろに置くAt first I was tired, because the bags were very heavy.
うしろに置くI like this town, because the air is fresh.
うしろに置くI am not afraid of hard work now, because I know that it is necessary for our town.
Why 〜? への答えWhy do you collect garbage? —— Because I love this river.

because と so を同じ文で重ねません。中1 Unit 4 の so（だから）は、理由を前、結果をうしろに置きます。because はその逆で、結果を前、理由をうしろに置きます。どちらか1つで足ります。

語前に来るものうしろに来るもの
because結果理由
so理由結果

that は内容を付け足す

that は「〜ということ」です。思っている内容・知っている内容・言った内容を、1つの文のまとまりで示します。

組む動詞例文
think（思う）I think that this volunteer event is important.
know（知っている）We know that plastic stays in the water for many years.
say（言う）My mother said that the weather will be dry this weekend.
hear（聞く）I heard that the local people cleaned up the beach last year.
notice（気づく）I noticed that the river was very dirty.
agree（賛成する）I agree that this rule is necessary.
promise（約束する）I promise that I will join the event again.

that のうしろも「主語＋動詞」をそろえた文です。I think that this volunteer event important. のように動詞を落とすことはできません。is が必要です。

形容詞と組む形もよく出ます。I am glad that you joined us.／I am sure that this story is true.　glad（うれしい）・sure（確信している）のうしろに、その理由になる内容を置きます。

that は省けることが多い

この that は、話しことばでも書きことばでも省かれます。意味は変わりません。I think this event is important.／We know plastic stays in the water for many years.　動詞のうしろに、いきなり「主語＋動詞」が続いていたら、省かれた that があると考えます。読解でこの読み方が要ります。

省けないのは、中1 Unit 3 で学んだ指示代名詞の that（あれ・それ）のほうです。こちらは文の主語や目的語になっているので、落とすと文が成り立ちません。

形を決める手順

  1. 付け足す内容が、時・条件・理由・内容のどれかを決める 時なら when、条件なら if、理由なら because、内容なら that です。
  2. 接続詞のうしろを「主語＋動詞」の文の形にする 語だけを置くことはできません。疑問文の語順にもしません。
  3. when と if のうしろなら、未来でも現在形にする 中心の文は will ＋ 原形のままです。3人称単数の -s は落としません。
  4. 説明の文を前に出したときだけコンマを置く うしろに置くときは要りません。that の文は前に出しません。

境界になる形

接続詞の that と指示代名詞の that

that のうしろを見ます。「主語＋動詞」が続いていれば接続詞、動詞や名詞が直接続いていれば指示代名詞です。I think that this event is important. の that は接続詞で、「あれ」とは訳しません。That is my bag. の that は指示代名詞で、文の主語です。

because のうしろに文が無い形

Why 〜? への答えでは Because I love this river. のように Because で文を始めます。これは、たずねられた中心の文が省かれているからです。答え以外の場面では、because だけの文で終わらせません。

if のうしろが過去形のとき

この単元の if は、これからのことを条件として置く言い方だけです。If it is sunny tomorrow, we will clean up the river. のように、うしろは現在形になります。過去形を置く言い方は中3で扱います。

ここまでに出た文をもう一度並べます。When I was a child, I lived near the forest.／If it is sunny tomorrow, we will clean up the river.／At first I was tired, because the bags were very heavy.／I think that this volunteer event is important.／I will call you when I get home.　どの文も、接続詞のうしろが「主語＋動詞」の形です。

ほかの例文です。Almost every student joined the event.／For example, I collect plastic bottles every week.／Trees cannot grow without water.／I know that plastic does not become part of nature.／Next month, we will plant seeds in a field near the school.／Our teacher explained the reason.／We collected the garbage for two hours.／Many local people helped us.／Please call me when you are free.／If it rains, I will stay home.

D英作文

日本語を英語にしましょう。語数の指定がある問題は、その語数で書きます。コンマは語数に数えません。短縮形は1語と数えます。

  1. もし明日晴れたら、私たちは川をきれいに片づけます。
  2. 私が子どものとき、私は森の近くに住んでいました。
  3. かばんがとても重かったので、私は疲れていました。
  4. 私は、プラスチックは自然の一部にならないということを知っています。
  5. that を使わずに「私はこの行事は大切だと思います」と書く。6語
  6. when を使って「あなたがひまなときに私に電話してください」と書く。7語
  7. if を使って「もし雨が降ったら、私は家にいます」と書く。7語

F自由記述

自分のことばで書きましょう。

  1. if を使って、明日の天気によって変わる自分の予定を1文で書く。例：If it is sunny tomorrow, I will play tennis in the park.
  2. I think that 〜 と because を使って、自分の好きな教科とその理由を2文で書く。例：I think that science is interesting. I like it, because I learn about nature.

解答と解説

問題を解き終えてから開きましょう。まちがえた問題は、接続詞のうしろが「主語＋動詞」になっているかを確かめ、次にwhen と if のうしろが現在形になっているかまで戻ります。

  1. イ　is

    if のうしろは、未来のことでも現在形です。中心の文の will clean up が未来を示しているので、条件の側では will を重ねません。

  2. ウ　because

    前が結果（疲れていた）、うしろが理由（かばんが重かった）なので because です。

  3. ア　When

    does があり ? で終わるので、時をたずねる疑問詞の When です。接続詞なら、うしろはふつうの語順になります。

  4. ウ　get

    when のうしろは現在形です。主語が I なので -s はつきません。

  5. イ　stays

    that のうしろもふつうの文なので、主語 plastic は1つのものとして扱い、中1 Unit 9 の決まりで -s がつきます。

  6. If it rains tomorrow, we will read about the environment in the classroom.

    条件の文を前に出すので、境目にコンマを置きます。rains の -s を落としません。

  7. When I was a child, I lived near the forest.

    説明の文を前に出した形です。I lived near the forest when I was a child. でも同じ意味ですが、語群の並びと日本語の順からはこの形です。

  8. I think that this volunteer event is important.

    不要な語は what です。内容を付け足すのは that です。that のうしろは「主語＋動詞」をそろえます。

  9. At first I was tired, because the bags were very heavy.

    結果を前、理由をうしろに置きます。at first は「はじめは」です。

  10. If the weather is sunny, we will work outside.

    不要な語は when です。晴れるかどうかは決まっていないので if です。

  11. I know that it is necessary for our town.

    知っている内容を that のうしろに文の形で置きます。

  12. If it rains tomorrow, we will read about the environment in the classroom.

    理由の例：if のうしろは、未来のことでも現在形にするから。

  13. When I get home, I will call you.

    理由の例：when のうしろも現在形にし、will は中心の文だけに使うから。

  14. Because the bags were very heavy, I was tired.

    理由の例：because と so を同じ文で重ねないから。The bags were very heavy, so I was tired. でも正解です。

  15. I think that this volunteer event is important.

    理由の例：that のうしろも「主語＋動詞」をそろえた文にするから。

  16. We know that plastic stays in the water for many years.

    理由の例：that のうしろもふつうの文なので、3人称単数の -s がつくから。

  17. If it is sunny tomorrow, we will clean up the river.

    We will clean up the river if it is sunny tomorrow. でも正解です。前に出したときだけコンマを置きます。

  18. When I was a child, I lived near the forest.

    I lived near the forest when I was a child. でも正解です。

  19. I was tired, because the bags were very heavy.

    The bags were very heavy, so I was tired. でも正解です。

  20. I know that plastic does not become part of nature.

    I know plastic doesn't become part of nature. でも正解です。that は省けます。

  21. I think this event is important.

    that を省いた形です。動詞のうしろに「主語＋動詞」が続くので、省かれた that があると分かります。6語です。

  22. Please call me when you are free.

    when のうしろは現在形です。7語です。

  23. If it rains, I will stay home.

    if のうしろは現在形で、rains の -s を落としません。7語です。

  24. ア

    Last spring, I joined a clean-up event near the river. と合います。ごみを集めたのは2時間なのでイは合わず、地元の人がユウタたちを手伝ったのでウも合いません。

  25. ア

    it stays in the water for many years と合います。イは植えるのが seeds（種）なので合わず、ウは雨なら教室で読むので合いません。

  26. plant

    本文の Next month, we will plant seeds in a field near the school. に合わせます。will のうしろなので原形です。

  27. ア

    if のうしろは、未来のことでも現在形で言います。主語が we なので -s もつきません。未来を示しているのは中心の文の cannot protect の側です。

  28. 私は、その川がとても汚れていることに気づきました。

    notice は「気づく」です。that のうしろの文が、気づいた内容です。「その川がとても汚いことに気がつきました」でも正解です。

  29. 解答例　If it is sunny tomorrow, I will play tennis in the park.

    if のうしろが現在形、中心の文が will ＋ 原形になっていれば正解です。

  30. 解答例　I think that science is interesting. I like it, because I learn about nature.

    1文目の that のうしろと、2文目の because のうしろが、どちらも「主語＋動詞」の文になっていれば正解です。

この単元のまとめ

接続詞 when（時）・if（条件）・because（理由）・that（内容）は、うしろに「主語＋動詞」をそろえた文を置きます。when と if のうしろは、未来のことでも現在形で言い、3人称単数の -s は落としません。説明の文を前に出したときだけコンマを置きます。because と so は重ねません。that は省けるので、動詞のうしろにいきなり「主語＋動詞」が続いていたら、省かれた that があると読みます。
